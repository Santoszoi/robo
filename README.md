# Robotron 2000 — exercício recuperado

Exercício educacional de manipulação do DOM em JavaScript, recuperado em 2026 a partir de um repositório antigo que estava incompleto e continha conflito Git não resolvido.

## Objetivos praticados

- eventos e manipulação do DOM;
- estado simples em JavaScript;
- atualização derivada de atributos;
- layout responsivo;
- controles acessíveis.

A ideia original **Robotron 2000** vem de material educacional da Alura. Esta versão é mantida como exercício de estudo e não é apresentada como produto ou conceito autoral.

Para projetos atuais e autorais, consulte o DeskFlow e os projetos destacados no perfil de Marcos Neves.
