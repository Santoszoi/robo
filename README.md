# Robotron 2000

Exercício educacional de JavaScript voltado a eventos, manipulação do DOM e atualização de estado na interface.

**Demo:** https://robo-iota.vercel.app

## Funcionalidades

- adicionar e remover componentes do robô;
- recalcular força, poder, energia e velocidade;
- limitar quantidades inválidas;
- restaurar a configuração inicial;
- layout adaptado para telas menores.

## Tecnologias

HTML5, CSS3 e JavaScript.

## Rodando localmente

```bash
git clone https://github.com/Santoszoi/robo.git
cd robo
python -m http.server 8000
```

Abra `http://localhost:8000`.

## O que pratiquei

O exercício foi útil para consolidar eventos, estado simples em JavaScript e atualização da interface a partir de dados derivados. A revisão também corrigiu o estado incompleto do repositório antigo e reorganizou a implementação.

## Origem do exercício

A proposta **Robotron 2000** faz parte de material educacional da Alura. Este repositório é mantido como exercício de estudo, não como conceito ou produto autoral.
